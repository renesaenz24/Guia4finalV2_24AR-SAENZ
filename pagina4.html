  1. Dominio

    2. En HTML, el término "dominio" se refiere al nombre de dominio de un sitio web, que es la dirección que los usuarios escriben en la barra de navegación para acceder a él.

  2. Sub dominio

    3. En HTML, el "subdominio" no es un elemento o etiqueta en sí, sino una característica que se utiliza en la dirección URL de un sitio web para organizar contenido o crear secciones separadas

  3. URL

    4. En HTML, la URL (Uniform Resource Locator) se utiliza para especificar la dirección o ubicación de un recurso web, como una página, una imagen o un archivo.

  4. DNS

    5. En HTML, el DNS (Domain Name System, Sistema de Nombres de Dominio) no es un elemento o atributo específico del lenguaje. El DNS es un sistema fundamental que permite a los navegadores web, y por lo tanto a las páginas HTML, acceder a los recursos en internet utilizando nombres de dominio fáciles de recordar, en lugar de direcciones IP numéricas.

  5. Hosting

    6. El "hosting" en el contexto de una página web HTML, o web en general, es el servicio que permite alojar los archivos de tu sitio web en un servidor para que sean accesibles a través de internet.

  6. FTP

    7. En HTML, FTP no es una etiqueta o elemento. FTP (File Transfer Protocol) es un protocolo de red que se utiliza para transferir archivos entre un cliente y un servidor

  7. HTTP

    8. En el contexto de HTML, HTTP (Hypertext Transfer Protocol) es el protocolo de comunicación que permite la transferencia de documentos hipertexto, como las páginas web, entre un navegador y un servidor web.

  8. HTTPS

    9. HTTPS es la versión segura del protocolo HTTP, que se utiliza para transferir datos entre un navegador web y un servidor.

  9. W3C

    10. El W3C (World Wide Web Consortium) es una organización internacional que desarrolla estándares y directrices para la World Wide Web, incluyendo HTML, CSS y otros lenguajes web.

  10. UTF-8

    11. En HTML, UTF-8 es una etiqueta que permite usar caracteres de cualquier idioma y símbolos especiales, incluyendo emojis, en tu página web

  11. HTML5 y su escritura

    12. HTML5 es la última versión del Lenguaje de Marcado de Hipertexto (HTML), que se utiliza para estructurar y organizar el contenido de una página web.
